# References

The agent should consult the repository's pinned documentation and local conventions first. Useful reference areas include:

- Playwright Test configuration, fixtures, locators, assertions, projects, tracing and reporters.
- GitHub Copilot custom agents, skills, tool permissions and MCP configuration.
- Accessibility guidance for keyboard navigation, labels, roles, focus and error messaging.
- The product's requirements, acceptance criteria, design system, API contracts and test-data policy.

Pin or vendor version-specific references in the target repository when reproducibility matters. Do not treat a reference link as evidence that an application behavior was observed. Record the URL/version/date used for material implementation decisions.
